About

부산대학교 기계공학부를 졸업하고 백엔드 개발자로 일하고 있습니다. 지금은 법무법인의 레거시 모놀리식 백엔드를 Kubernetes 위 Java/Spring MSA로 전환하는 일을 하고 있습니다.

신원·인증 플랫폼과 GitOps 배포 파이프라인을 직접 구축했고, 바꾸려는 대상의 실제 사용 데이터를 먼저 측정해서 설계 근거로 삼는 방식을 좋아합니다. TypeScript/Node.js·PostgreSQL과 Java/Spring이 주력이고, Go와 Rust로 운영 도구를 만듭니다.

이 사이트

정적 파일을 S3에 두고 CloudFront로 서빙합니다. AWS Organization부터 인증서·DNS까지 전부 OpenTofu로 관리하고, 소스는 GitHub에 있습니다.

처음에는 《The Rust Programming Language》 마지막 장 예제에서 출발한 Rust 표준 라이브러리 HTTP 서버로 EC2에서 직접 서빙했습니다. 그 서버는 지금도 로컬 개발용으로 이 페이지를 띄웁니다.
